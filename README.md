An early personal website project built with HTML, CSS, and JavaScript to present personal information, skills, and projects.

## ✨ Project Areas
- Personal introduction and profile pages
- Project and skills sections
- Multi-page website structure
- Styling and client-side interactions

- HTML
- CSS
- JavaScript

## 🚀 Run Locally
Clone the repository and open `index.htm` in a web browser. If the site references local assets, keep the existing folder and file structure intact.
